# CAPTCHA guard patch provenance

`packaging/solver-patches/` contains the KidTE integration patch, its two
hash-pinned solver snapshots, and the installer/test helpers. The upstream
solver project is [gbiz123/tiktok-live-studio-captcha-solver](https://github.com/gbiz123/tiktok-live-studio-captcha-solver).
The adjacent `manifest.json` records the source hashes, patch hashes, and the
upstream change reference used when this patch was assembled. Its
`integration_verified` field records the verification state for that snapshot.

The snapshots are retained for patch verification and regression tests. This
note does not grant a license or change the upstream project's licensing;
redistributors should follow the upstream project's license and attribution
terms alongside KidTE's own terms.
